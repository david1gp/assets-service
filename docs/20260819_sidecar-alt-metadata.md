# Sidecar md/txt → alt metadata

## Goal
Automatically load companion `.md`/`.txt` sidecar files next to images as `alt` text into asset metadata, via the `assets` CLI (diff/upload-all). Then regenerate abikur, rerun, and verify alt matches sidecar content.

## Key facts
- `alt` already exists: `src/metadata/imageMetadataSchema.ts` (`alt: v.nullable(v.string())`), stored as JSON in `asset_metadata.metadata` (no DB migration needed).
- Server already supports setting alt: `metadataSetRequestSchema = { alt maxLength 10000 }` → `src/asset/assetApiRepositoryCreate.ts` updates the JSON metadata. Route exists (see `test/apiAssetRoutes.test.ts`). Prod is 0.2.4 (already deployed) → server side ready.
- CLI gap (client-side only):
  - `src/asset-cli/configuredRootScan.ts:83-95` skips `.md`; `.txt` under images → `unsupported` in `src/asset-cli/assetSourceMediaTypeRead.ts`.
  - `src/entrypoints/assets-cli.ts` (`upload-all` ~723-1049, `diff` ~1146-1185) filters out `.md`.
  - Upload contract carries no alt (`uploadIntentRequestSchema`, `uploadCompletionRequestSchema`).
  - Diff is byte-fingerprint only: `src/asset-cli/assetDiffClassify.ts:184-200`, `src/asset-cli/assetFileFingerprint.ts`. alt not compared.
  - Remote manifest: check whether `src/asset-cli` remote list entry exposes `metadata.alt` and asset id (needed to compare + to call metadata-set).
  - API client: check it has a `metadataSet(projectId, assetId, {alt})` method; if not, add it.
- abikur: `Image.tsx` renders `image.metadata.alt ?? basename`; `src/app/assets/imageList.ts` generated with `alt:null`. List regeneration lives in `src/app/assets/{assetsProcess,package}.ts`.
- Remote CLI runs via `bunx assets` (leo-server abikur node_modules currently 0.2.2). New CLI must reach leo-server (dep bump/publish) for rerun.

## Decisions
- Reuse the existing metadata-set API from the CLI (NO upload-contract or DB changes). After an asset exists on the server (new/changed uploaded, or matching), if sidecar alt differs from remote alt, call metadata-set.
- Sidecar pairing: same directory, image stem + `.md` (preferred) else `.txt`. Content = trimmed file text; empty/whitespace → null; enforce ≤10000 chars. Optional per image.
- Stop treating md/txt as conflict/unsupported: consume them as sidecars, not standalone assets.
- Diff: surface sidecar alt differing from remote alt as a distinct status (e.g. `metadata`) or `changed`, not `conflict`. Requires remote manifest to expose alt.
- Version: bump minor (0.2.5) after feature; build + full test; publish so leo-server CLI can use it.
